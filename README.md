# 💬 Real-Time Chat Application

## 📌 Project Description
This is a real-time chat application developed using Node.js and Socket.IO. It allows multiple users to join chat rooms and communicate instantly. The application uses MongoDB for storing messages and supports live user updates.

---

## 🚀 Features
- Real-time messaging using WebSocket (Socket.IO)
- Multiple chat rooms
- Join and leave notifications
- Online users list
- Message storage using MongoDB
- Clean and responsive user interface

---

## 🛠️ Technologies Used
- Node.js
- Express.js
- Socket.IO
- MongoDB (Mongoose)
- HTML
- CSS
- JavaScript

## 💡 How It Works
- Users enter a username and room name
- Users join a chat room
- Messages are sent in real-time using Socket.IO
- Messages are stored in MongoDB database
- Online users are displayed dynamically
- Users can leave and rejoin rooms without refreshing
